# 07 — 建设上下文工程与分层记忆

> 执行计划，尚未实施。前置：04–06。下一步：[08 动态调度](08-consistency-first-scheduler.md)。

## 任务目的

让每个 AI 在正确时间获得正确资料：足以理解当前内容，又不会被无关材料、旧解释或机器自证淹没。

上下文不是一份越来越长的总提示词，而是由任务目标、证据关系和角色职责组织的工作材料。

## 需要做什么

1. 为研究、翻译、原意检查、全局一致性和中文编辑分别设计资料选择策略。
2. 建立实体/字段/场景检索、精确词面检索和语义召回，使跨文件权威用法能主动被找到。
3. 检索结果保存来源、版本、适用范围和原始片段；让角色能够回到原文，而非只读摘要。
4. 区分长期权威、原文事实、当轮工作记忆和方法经验；不能用统一“记忆库”忽略来源差别。
5. 为长场景建立层级语义说明与角色状态，但摘要不得替代全部原文证据。
6. 允许任务主动要求更多上下文，并将请求交给调度器处理。
7. 建立上下文过时检测；已撤回权威、旧契约或改变含义的源文不能继续作为新任务依据。

## 要新增的功能

- **角色上下文包**：每种角色看到它完成工作所需的事实、引用、候选和约束。
- **作品检索**：查询一个实体的所有使用场景、一种机制的权威表达、一个角色的代表台词。
- **资料充分性检查**：信息不足时明确返回缺口，不把检索结果最多的解释当最可靠解释。
- **分层长文记忆**：全局人物背景、当前场景、当前发言分层提供，防止超长资料挤掉关键句。
- **证据反查**：任何摘要和结论可跳回具体原文；有争议时重新读取。
- **缓存分级**：原始资料、已核验知识、固定任务结果与未审机器草稿采用不同复用规则。

## 允许积极使用检索，但不能错用

不预先排除向量检索、重排序和混合召回。它们可帮助发现跨语言、不同写法和相邻场景的资料，这是作品级理解的重要能力。

直接写入译文仍需证明是同一语义和适用场景。相似技能、数值变化、否定差异、不同说话人以及不同版本，不得因相似度高而直接复用。

模型重排和 Jev 评分只决定“值得看什么”，不是决定“这就是正确答案”。没有合适材料时可返回空。

## 压缩和缓存的约束

压缩应先删无关内容，不能优先删负面例子、否定词、机制条件或权威冲突。输入过长可以分层研究、拆任务和回查；不能把截断后的内容当完整原文。

精确恢复同一任务已验证的草稿是断点续作；把它拿去指导独立任务的译名是知识复用，两者必须区分。缓存失效包含源版本、契约、模型任务参数和依赖知识变化。

## 交付与完成标准

在一个跨剧情、技能和语音的实体问题上，资料系统能找到相关权威与原文，说明选择理由、缺失资料及可能冲突。

验证语义检索错误近邻、过时资料、摘要遗漏条件、同名字不同实体等反例；检索和压缩不能提高表面命中率却增加错翻。
