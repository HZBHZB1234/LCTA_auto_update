# 09 — 实现按语义域的联合起草

> 执行计划，尚未实施。前置：04–08。下一步：[10 全局一致性](10-global-consistency.md)。

## 任务目的

从“每个字段独自生成”转向“相关内容作为作品的一部分共同起草”。在共同理解与编辑契约就绪后，AI 才开始写中文。

联合起草不等于把所有字段塞进一条超长请求。它意味着共享证据、共同决定和结果互相可比较。

## 需要做什么

1. 为剧情、角色语音、战斗机制、技能/效果和 UI 建立不同的起草方式；共同遵守正确性与契约，表达策略因文本类型而异。
2. 将一个一致性域拆为可执行翻译包，每包保留原文上下文、实体身份、术语适用性和已确认权威表达。
3. 对新实体同时查看相关名称、描述、对白和引用，提出适用于该域的一组候选；不得只译第一项再把它当权威传播。
4. 支持候选 A/B 在争议领域比较，同时说明原意与风格取舍；模型自报“更好”不是验收。
5. 已有权威中文的完整句子按版本和含义直接采用；相似句只供参考，数值/条件/角色差异必须保留。
6. 使游戏格式字段、占位符、标签和 ID 在写回时保持完整；无法安全写回的候选退回修复/待审。
7. 让稿件明确标注权威采用、共同任务临时选择、独立生成及尚未解决问题，不把所有中文字串视为相同资格。

## 要新增的功能

- **领域工作包**：同一角色的相关台词、同一效果的技能与描述一起起草和审看。
- **上下文适配**：剧情提供人物与邻接对话，机制提供条件和引用图，UI 提供使用场景与长度要求。
- **联合候选板**：能查看同一实体在全部相关稿件中的写法及理由，允许一次决定应用多处编辑。
- **可编辑范围**：直接复用的权威正文不可由生成任务修改；机器草稿可定向重写。
- **候选比较**：比较忠实度、角色声音和域内一致性，不以多数采样充当正确性证明。
- **延迟提交**：草稿生成后仍需原意和一致性审校，不能在模型返回时就进入最终包。
- **来源隔离**：工作包中的临时名称仅在该编辑过程可见，下一轮长期资料仍以权威来源为准。

## 如何发挥 AI 的长处

让模型在相关上下文中完成翻译方案、句式重组、人物声音控制和局部难点解释；允许它指出契约缺陷并申请新研究。

针对中文信达雅，可以提供权威台词和场景节奏作为风格参照，但不能要求照抄类似句子，不能通过套用一个“统一文风”抹掉角色差异。

对新名允许生成多个候选并比较其原文依据、角色/世界观含义和后续使用便利；确定在本域采用哪一种仍是临时编辑决定，等待权威到达再收敛。

## 完成标准

一组相互关联的真实文本能够在共同契约下产出完整候选，没有遗漏字段或标签损坏；跨文件名称和机制表达可共同审阅和修订。

单个字段独立翻译结果即使通顺，只要与同域其它结果矛盾，就不能被当成最终完成。新增联合起草不能增加机制误解、错误指代或原文没有的细节。
