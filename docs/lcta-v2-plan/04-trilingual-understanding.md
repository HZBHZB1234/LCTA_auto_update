# 04 — 建设三语共同理解与作品关系图

> 执行计划，尚未实施。前置：02–03。下一步：[05 权威与术语体系](05-authority-and-terminology.md)。

## 任务目的

让 AI 先理解“这次更新在讲什么、哪些内容属于同一件事”，再进入中文写作。把日韩英三语从被动附录变成研究与求证的核心能力。

## 需要做什么

1. 用实际游戏身份与结构建立可追踪文本单元，识别角色、效果、技能、剧情、语音和 UI 等领域。
2. 建立三语平行对应；稳定 ID、嵌套身份和场景锚点优先，不能沿用剧情数组下标天然一致的假设。
3. 引入三语研究角色，为机制内容提取行动者、对象、条件、数值、否定和顺序，为叙事内容分析人物关系、视角、情绪、敬语、隐喻和歧义。
4. 将原文支持的实体、关系、事件、机制概念关联到相关字段，形成作品关系图。
5. 对高风险歧义先独立读解 KR/JP/EN，再进行对照，避免一个译本的解释污染所有判断。
6. 允许研究角色主动请求邻接场景、人物既有台词、关联技能、名称来源和对应版本，问题得到回答后再推进。
7. 保存理解结论、短证据引用、竞争解释和不确定项，不把模型未展示的推理过程当审计资料。

## 要新增的功能

- **更新语义概览**：指出新增人物、机制、故事关系与受影响旧内容。
- **三语分歧报告**：区分缺失、不同版本、意译差异、真实语义冲突。
- **实体与提及关联**：把同一人物的全称、称呼、代词和多语写法联系起来，保留同形异义。
- **机制语义说明**：支持“至少/超过”“触发前/后”“自身/对象”等可导致错翻的区别。
- **场景地图**：识别说话人、受话人、相邻对话和叙事单元，供以后联合翻译。
- **主动求证**：将资料缺口转成有明确问题的任务。
- **理解版本化**：发现反例后可以修订理解，并使相关下游工作失效。

## 自动化与证据

有原文明确依据、身份对应可靠且通过核验的事实可以自动进入原文知识；不需要逐条等人工批准。

猜测性的关系和文化解释保留为假设，带适用范围，不用于强制下游表达。语义相似的名称不能直接合并实体。多个语言一致也不能自动证明它们没有共同误译。

缺少某种语言时使用实际可用资料，并公开缺口。KR 原文通常是基准，但原文自身疑似缺陷时允许专门调查，不能机械选择英文或韩文代替求证。

无法确定的关键机制和身份先自动补证、换用已验证的独立读解；仍不能解决则登记等待相关原文或权威更新的恢复条件。无关内容继续，不将人工处理设为恢复前置。

## 旧能力取舍

可迁入已经验证的游戏解析经验和稳定 ID 规则。旧展平器、按数组位置的对齐、仅按韩文子串召回可以作为材料，不能定义新系统的理解边界。

不要求引入图数据库；先保证图上的每条重要关系都能回答“来自哪里、在哪个范围成立、谁依赖它”。

## 交付与完成标准

给定一次真实更新，应能形成可读的更新概览、三语对照、作品关系图及待求证清单。后续角色无需重新猜测所有上下文。

测试须覆盖剧情插行、同句同形多义、英文日文落后、效果 ID 相同但领域不同。错误对应不能被标成已确认；生成任何中文之前就应发现这些风险。
